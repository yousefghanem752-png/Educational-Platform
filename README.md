# EduPlatform - Educational Platform

A fully responsive, feature-rich front-end web application for an educational platform. This project is built using HTML5, CSS3, and Vanilla JavaScript, demonstrating a modern UI/UX for online learning.

## 🚀 Features

- **User Authentication:** Login and Registration pages with form validation.
- **Role-based Access:** Dedicated interfaces for Students, Instructors, and Administrators (`dashboard.html`, `instructor.html`, `admin.html`).
- **Course Catalog:** Browse featured and all courses with functional pagination.
- **Advanced Search & Filtering:** Filter courses by category (Programming, Design, Data Science) and search by keywords.
- **Dynamic Views:** Toggle between Grid and List views for the course catalog.
- **Dark/Light Mode:** Integrated theme toggle for better accessibility and user experience.
- **Multi-language Support:** Language toggle functionality (e.g., English / Spanish).
- **Mock Data Integration:** Uses `fakeData.js` to simulate a real backend database and populate content dynamically.

## 🛠️ Technologies Used

- **HTML5** (Semantic structure)
- **CSS3** (Custom styling, Flexbox/Grid, Responsive Design)
- **Vanilla JavaScript** (DOM manipulation, state management, OOP concepts)

## 📁 Project Structure

- `index.html`: Home page featuring hero section and dynamic course catalog.
- `dashboard.html`: User/Student dashboard.
- `admin.html`: Administrator control panel.
- `instructor.html`: Instructor management interface.
- `login.html` & `register.html`: User authentication pages.
- `course.html`: Individual course details view.
- `scholarships.html`: Information regarding scholarships.
- `contact.html`: Contact form page.
- `/css`: Contains all stylesheets (e.g., `style.css`).
- `/js`: Contains logic modules (`app.js`, `auth.js`, `courses.js`, `ui.js`).
- `/data`: Contains mock database (`fakeData.js`).
- `/assets`: Contains images and icons.

## ⚙️ How to Run Locally

1. Clone this repository to your local machine:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd "Educational Platform Project 2"
   ```
3. Open the `index.html` file in your preferred web browser. No local server, Node.js, or build tools are required!
